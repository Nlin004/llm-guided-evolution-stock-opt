constants module¶

constants.DATA_PATH = './cifar10'¶

DATA_PATH absolute or relative to ExquisiteNetV2

constants.FITNESS_WEIGHTS = (1.0, -1.0)¶

Tuple of fitness weights of length equal to the number of objectives. 1.0 indicates objective will be maximized, -1.0 for objective to by minimized.

constants.GENERATION = 0¶

Cycle in the optimization and output directory where intermediate data will be stored.

constants.INFERENCE_SUBMISSION = True¶

Whether (True) or not (False) to submit LLM prompts remotely to sources such as hugging face.

constants.LLM_BASH_SCRIPT_TEMPLATE = '#!/bin/bash\n#SBATCH --job-name=llm_oper\n#SBATCH -t 8:00:00\n#SBATCH --gres=gpu:1\n#SBATCH -C "{}"\n#SBATCH --mem-per-gpu 16G\n#SBATCH -n 12\n#SBATCH -N 1\necho "Launching AIsurBL"\nhostname\n\n# Load GCC version 9.2.0\n# module load gcc/13.2.0\n# module load cuda/11.8\nmodule load cuda\nmodule load anaconda3\n# Activate Conda environment\nconda activate llm_guided_env\nexport LD_LIBRARY_PATH=~/.conda/envs/llm_guided_env/lib/python3.12/site-packages/nvidia/nvjitlink/lib:$LD_LIBRARY_PATH\n# conda info\n\n# Set the TOKENIZERS_PARALLELISM environment variable if needed\n# export TOKENIZERS_PARALLELISM=false\n\n# Run Python script\n{}\n'¶

Template script for submitting a prompt to the LLM

constants.LLM_GPU = 'A100-40GB|A100-80GB|H100|V100-16GB|V100-32GB|RTX6000|A40|L40S'¶

If using slurm, this string will be used to request GPUs for the submission of prompts to the LLM.

constants.LLM_MODEL = 'gemini'¶

LLM Model to use. Choices currently include [‘gemini’, ‘mixtral’, ‘llama3’]

constants.LOCAL = True¶

Whether to run llm-ge locally (True) or distribute across a slurm cluster (False)

constants.MACOS = False¶

Whether host uses macOS (True) and should use mps, or not (False) and should use cpu or cuda depending on what is available

constants.NUM_EOT_ELITES = 10¶

Number of elite individuals to utilize within the Evolution of Thought (EOT) operation

constants.PYTHON_BASH_SCRIPT_TEMPLATE = '#!/bin/bash\n#SBATCH --job-name=evaluateGene\n#SBATCH -t 8:00:00\n#SBATCH --gres=gpu:1\n#SBATCH -C "A100-40GB|A100-80GB|H100|V100-16GB|V100-32GB|RTX6000|A40|L40S"\n#SBATCH --mem-per-gpu 16G\n#SBATCH -n 12\n#SBATCH -N 1\necho "Launching Python Evaluation"\nhostname\n\n# Load GCC version 9.2.0\n# module load gcc/13.2.0\nmodule load cuda\nmodule load anaconda3\n# Activate Conda environment\nconda activate llm_guided_env\nexport LD_LIBRARY_PATH=~/.conda/envs/llm_guided_env/lib/python3.12/site-packages/nvidia/nvjitlink/lib:$LD_LIBRARY_PATH\n# conda info\n\n# Set the TOKENIZERS_PARALLELISM environment variable if needed\n# export TOKENIZERS_PARALLELISM=false\n\n# Run Python script\n{}\n'¶

Template script for submitting job for evaluation.

constants.QC_CHECK_BOOL = False¶

Whether (True) or not (False) you wish to run quality control checks on responses from the LLM

constants.ROOT_DIR = '/home/hice1/jzutty3/llm-guided-evolution'¶

Root directory of the repository

constants.SEED_NETWORK = '/home/hice1/jzutty3/llm-guided-evolution/sota/ExquisiteNetV2/network.py'¶

Location where the network architecture for the seed resides

constants.SOTA_ROOT = '/home/hice1/jzutty3/llm-guided-evolution/sota/ExquisiteNetV2'¶

Location where the current seed repo resides

constants.crossover_probability = 0.35¶

Probability of mating two individuals

constants.hof_size = 100¶

Number of individuals to keep in the hall of fame across the optimization

constants.mutation_probability = 0.8¶

Probability of mutating an individual

constants.num_elites = 44¶

Number of elites to consider

constants.num_generations = 30¶

Number of generations to run for

constants.population_size = 8¶

Population size to utilize in each generation after optimization begins

constants.start_population_size = 32¶

Population size for launching optimization
